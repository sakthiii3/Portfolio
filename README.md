# Sakthi Sundaresan S - Modern Developer Portfolio

A professional, responsive, and high-performance developer portfolio built with the latest web technologies.

## 🚀 Tech Stack
- **React 19** + **Vite 8** + **TypeScript**
- **Tailwind CSS 4** (Modern CSS-first approach)
- **Framer Motion** (Cinematic animations and transitions)
- **Lucide React** & **Simple Icons** (Premium iconography)

## ✨ Key Features
- **Cinematic Hero Section**: High-contrast, bold design with portrait integration.
- **The Arsenal**: A dense, interactive grid of technical skills with brand logos.
- **Internships & Experience**: Detailed modules highlighting professional training and leadership.
- **Projects Gallery**: Hover-active cards with live demo and source code links.
- **Light/Dark Mode**: Seamless theme switching with persistent user preference.
- **Responsive Design**: Fully optimized for mobile, tablet, and desktop viewing.

## 🛠️ Installation & Setup

1. **Clone the repository**:
   ```bash
   git clone https://github.com/sakthiii3/Portfolio.git
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run in development mode**:
   ```bash
   npm run dev
   ```

4. **Build for production**:
   ```bash
   npm run build
   ```

## 🌐 Deployment
This project is production-ready for deployment on **Vercel**, **Netlify**, or **GitHub Pages**.
